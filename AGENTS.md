# drobu — учебный сайт «Дроби та відсотки на піці»

## Как запускать / проверять
- Статический сайт: `index.html` + `style.css` + `script.js`, без сборки и зависимостей. Достаточно открыть `index.html`.
- Проверка после правок: `check_preview` (ошибок JS быть не должно).

## Структура (8 тем, по порядку в `index.html`)
1. `#story` — что такое дробь (интерактивные шаги)
2. `#parts` — числитель/знаменатель
3. `#mixed` — смешанные числа (галерея `#mixedGallery`); только одинаковые знаменатели
4. `#adding` — сложение/вычитание с одинаковыми знаменателями
5. `#diffden` — разные знаменатели (НОК), в конце — блок «Чому було 1/2 і 1/3, а стало ?/6»
6. `#multiply` — умножение дробей: правило + пошаговая презентация «скорочення навхрест» (4/9 × 3/8, обе диагонали) + пример на пицце
7. `#divide` — деление дробей: правило + визуал `#divGrid` + примеры с сокращением навхрест (без интерактивной презентации)
8. `#percent` — проценты
Оглавление — `#map`; меню в `nav` повторяет нумерацию; правый рельс `.rail` (на мобильных — нижняя полоса) подсвечивает текущую тему.

## Тема оформления
- Переключатель `#themeToggle` — **фиксированная кнопка в правом верхнем углу** (`.theme-toggle{position:fixed;top:14px;right:16px;z-index:400}`), видна на всех экранах; режим хранится в `localStorage['drobu-theme']`, **по умолчанию светлая** (системная тема игнорируется).
- Логотипа «🍕 Дроби» в шапке нет — убран специально, не возвращать.
- Тёмная палитра — через `html[data-theme="dark"]`: **вручную подобрана по блокам** (не инверсия). Новые блоки со светлым фоном нужно добавлять в список тёмных правил.
- В тёмной теме **никаких белых обводок/теней**: инсеты `rgba(255,255,255,...)` в тёмном слое заменены на `rgba(0,0,0,.55)`; границы карточек — тёмно-фиолетовые `rgba(109,89,170,.32)`. Градиенты остаются насыщенными (секции не «выключаются» в плоский фон).
- Героическая пицца (`.hero-pizza svg`) имеет обводку (`drop-shadow(0 3px 0 var(--outline))`) и тень в обеих темах.
- Десктопный слой (`@media(min-width:901px)` по факту — правила до блока `@media(max-width:900px)`): `.auras` (плавающие градиентные пятна), стеклянные карточки с подсветкой под курсором (CSS-переменные `--mx/--my` ставятся в `script.js`), блик на кнопках, градиентные заголовки.
- Мобильный слой (`@media(max-width:900px)`): мультяшный стиль — толстые чёрные обводки, «объёмные» тени `0 6px 0 var(--ink)`, кнопки с нажатием, ауры и стекло отключены.

## Правила проекта
- Язык интерфейса — украинский, стиль дружелюбный, «на піцах».
- Вся визуализация дробей — SVG-функция `makePizza(slices, eaten, size)` в `script.js` (eaten — индексы пустых/съеденных кусков).
- Дроби в тексте пишем простой записью `1/2`, крупные дроби — через `fracHTML()` / `.big-frac`.
- В примерах на вычитание НЕ перечёркивать куски (`.seg.removed`): показывать только то, что осталось.
- Блок «Чому було 1/2 і 1/3, а стало ?/6» — последний блок теории темы «різні знаменники» (піци до/після розрізання, без анімації-перемикання).
